# 一键启动脚本 - RemoteDesktop 信令服务器 + ngrok

## 使用步骤

### 1. 获取ngrok Token
1. 打开: https://dashboard.ngrok.com/signup
2. 注册免费账号
3. 登录后点击 "Getting Started"
4. 复制 "Authtoken" 的值

### 2. 配置脚本
打开 `启动ngrok.bat`，修改第8行：
```batch
set NGROK_AUTH_TOKEN=你的实际token值
```

例如：
```batch
set NGROK_AUTH_TOKEN=2xYz1234abcDEFghIJKlmno_abcdefghijklmnop
```

### 3. 双击运行
双击 `启动ngrok.bat`，等待启动完成

### 4. 记录信息
启动后会显示：
- 局域网地址: http://192.168.1.3:8000
- 公网URL: https://xxxx.ngrok.io
- 当前Token: XXXXXX

### 5. Android连接
- 服务器: `https://xxxx.ngrok.io`
- Token: 从脚本输出中获取

## 备用方案：WiFi测试
如果暂时不想配置ngrok：
1. 手机连接与电脑相同的WiFi
2. Android设置:
   - 服务器: http://192.168.1.3:8000
   - Token: 从API获取

## 获取Token
```bash
curl -X POST http://localhost:8000/api/token
```
